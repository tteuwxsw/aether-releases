# Aether releases

Este repositório publica os arquivos de atualizacao do aplicativo Aether.

Conteudo de cada release:

- `Aether-Setup-<versao>.exe` - instalador para Windows.
- `Aether-Setup-<versao>.exe.blockmap` - dados de diferenca incremental.
- `latest.yml` - metadados usados pelo atualizador do aplicativo.

O codigo-fonte do Aether e mantido em repositorio privado. Nenhuma credencial e
armazenada neste repositorio.
